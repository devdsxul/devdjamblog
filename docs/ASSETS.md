## sadgrl.online 平铺背景

早期版本用过 sadgrl.online 的平铺背景（<https://sadgrlonline.github.io/archived-sadgrl.online/webmastery/downloads/tiledbgs.html>）。当前设计桌面、窗口、进站页全部为纯色（白 / 黑），已不再打包任何平铺背景。

## 字体

- 进站页大字使用 [UnifrakturMaguntia](https://github.com/google/fonts/tree/main/ofl/unifrakturmaguntia)（SIL OFL 1.1，许可证见 `assets/fonts/OFL.txt`），本地打包在 `assets/fonts/`。
- 界面文字使用 98.css 自带的 "Pixelated MS Sans Serif"。

## 98.css

Win98 窗口、按钮、滑杆样式与像素字体 "Pixelated MS Sans Serif" 来自 [98.css](https://github.com/jdan/98.css) v0.1.20（MIT，许可证见 `assets/98/LICENSE`），本地打包在 `assets/98/`。

## 本项目绘制

- 播放器控制 SVG 图标、`favicon.svg`。
- 打碟机转盘/唱臂、左侧侧边栏、控制面板、进站页、星星拖尾等均为 CSS / JavaScript 实现，不含外部图片。
