# DEVDJAM 站主使用说明

## 进入控制室

网站地址后加 `/wp-admin/admin.php?page=devdjam` 即可进入。前台页脚的 `control room ↗` 也会打开后台。未登录时会先出现 WordPress 登录页。

本地预览的账号信息在项目 `.runtime/preview-access.json`。生产环境使用你部署时设置的账号，两者彼此独立。

控制室显示杂谈、音乐分享、Beats 的真实已发布数量和草稿数量。新站三个数字均为零。

## 发一篇杂谈

1. 控制室点击「写点什么」，或进入 WordPress 的「文章 → 写文章」。
2. 填写标题、正文；按需添加图片、分类、标签和特色图片。
3. 尚未完成时保存草稿，完成后点击发布。
4. 已发布内容出现在前台 `blog` 和首页最新动态中。

音乐分享的操作相同，入口是「DEVDJAM → 音乐分享」。这类文章出现在 `music` 栏目，方便与日常杂谈分开。

## 上传自己的 Beat

1. 点击「DEVDJAM → Beats → 新增 Beat」。
2. 标题填写曲名，正文填写介绍或制作笔记。
3. 在「音轨资料 / Tape details」中点击 **选择或上传音频**。
4. 在 WordPress 媒体窗口上传文件，或选择以前上传的音频，再点击 **使用这段音频**。
5. 音轨资料里会出现文件名和试听控件。BPM、调性均可留空。
6. 右侧的「特色图片 / 特色图像」用于封面；没有封面时，网站使用磁带图形。
7. 点击发布。新曲目会出现在 Beats 页面和播放器的 `PLAY QUEUE` 中。

建议网页试听使用 MP3、M4A 或 Ogg。WAV 也可以上传，但文件较大，访客等待和服务器流量都会增加。Docker 示例配置的单文件上传上限为 256 MB；普通 WordPress 安装的上限由你的服务器配置决定。

未选有效音频时，发布操作会提醒补充，记录保留为草稿。草稿不会出现在公开曲库。WordPress 媒体附件使用公开 URL，草稿状态控制的是内容展示。

## 修改和删除

- **改曲名、BPM、调性或介绍**：打开对应 Beat，修改后点击更新。
- **替换音频**：重新选择或上传音频，然后更新。这会更换关联，不自动删除旧文件。
- **移除关联**：解除当前 Beat 与音频的关联。若该 Beat 已发布，将保存为草稿，避免曲库中出现没有音源的曲目。
- **删除文章 / Beat**：先移入回收站，可以在回收站里恢复；彻底删除是单独操作。
- **删除音频文件**：在媒体库中删除。一个音频可能被多个地方引用，删除后相应曲目无法继续播放。

后台修改后，前台刷新或切换栏目会重新读取曲库。正在播放的音频会尽量维持，撤下当前曲目后重新加载曲库会停止它。

## 播放器

- 首次进入网站不会自动出声。点击一首 Beat 或播放器播放按钮后开始播放。
- 支持播放 / 暂停、上一首 / 下一首、拖动进度、音量、展开队列选曲。
- 在站内导航切换首页、音乐、Beats、杂谈、链接和关于时保持播放。
- 刷新整个网页、离开本站或打开管理后台会重新加载页面；重新进入后等待访客手动播放。
- 网络或音源出错时显示提示和重试按钮。
- 音量偏好保存在访客自己的浏览器。页脚 `effects` 可以减少装饰动效，也会遵守系统的减少动态效果设置。

## 链接、关于和首页

「链接」和「关于」是 WordPress 页面，在后台「页面」列表中编辑即可。它们初始正文为空，前台显示简短的空状态。

首页自动读取最新已发布内容。欢迎文字、背景和拼贴属于主题设计，不会作为虚构文章或歌曲进入数据库。外观素材路径与来源记录在 `ASSETS.md`。

## 保存自己的内容

服务器备份应同时包含数据库与 `wp-content/uploads`，否则只有文字记录或只有音频文件都不完整。Docker 部署的数据卷和备份方法见 `DEPLOYMENT.md`。


## 留言簿、控制面板、打碟机、进站页（2026-09-15）

- 「留言簿」页面开放评论，访客填名字和留言即可提交；后台「评论」菜单里审核、回复或删除。其他页面和文章默认关闭评论。
- 右上角「控制面板」：语言下拉（EN / 中文，只切换界面文案，不翻译你写的内容）、三套配色（milk 白底 / ink 黑底 / cherry 红色点缀）、动效开关（星星拖尾、跑马灯、进站页闪烁）。选择保存在访客自己的浏览器里。
- 每个窗口标题栏的 _ 和 □：最小化后再点一次恢复；□ 会把这个窗口弹出到最上层放大显示，其他窗口原地不动（留一个虚线占位），点暗色遮罩、按 Esc 或再点 □ 收回。同一时间只弹出一个。状态只在本次访问内保留。
- 左侧常驻侧边栏是主导航，底部有后台入口、播放指示灯和时钟。
- 「dj deck」打碟机：转盘按住拖动可搓碟（拖动时暂停、松手继续）；cue 回到开头；loop 单曲循环；shuffle 随机下一首；pitch 变速 ±8%（旁边 0 归零，bpm 读数会跟着变）；low / mid / hi 三段均衡（浏览器支持 Web Audio 时生效，不支持则静默忽略）。
- 进站页：每次新开浏览器会话第一次访问会显示哥特体大字 "you are now entering devdjam's world"，点击进入；同一会话内不再出现。
- 贴纸散落在各窗口角和栏目空隙里，都能点：有动效并触发对应动作（换配色、下一首、静音、跳转栏目等）。
- 左栏「访客」计数器是真实数据：每个浏览器每天记一次，保存在 WordPress 选项 `devdjam_hits` 里。
