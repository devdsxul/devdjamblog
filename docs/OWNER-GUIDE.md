# DEVDJAM 站主使用说明

## 进入控制室

网站地址后加 `/wp-admin/admin.php?page=devdjam` 即可进入。前台导航栏的钥匙图标（`admin / 后台`）也会打开后台；窄手机屏位于底部任务栏。未登录时会先出现 WordPress 登录页。

本地预览的账号信息在项目 `.runtime/preview-access.json`。生产环境使用你部署时设置的账号，两者彼此独立。

控制室显示杂谈、音乐分享、Beats 的真实已发布数量和草稿数量。新站三个数字均为零。

## 发一篇杂谈

1. 控制室点击「写点什么」，或进入 WordPress 的「文章 → 写文章」。
2. 填写标题、正文；按需添加图片、分类、标签和特色图片。
3. 尚未完成时保存草稿，完成后点击发布。
4. 已发布内容出现在前台 `blog` 和首页最新动态中。

音乐分享的操作相同，入口是「DEVDJAM → 音乐分享」。这类文章出现在 `music` 栏目，方便与日常杂谈分开。

## 上传自己的 Beat

1. 点击「DEVDJAM → Beats → 新增 Beat」。
2. 标题填写曲名，正文填写介绍或制作笔记。
3. 在「音轨资料 / Tape details」中点击 **选择或上传音频**。
4. 在 WordPress 媒体窗口上传文件，或选择以前上传的音频，再点击 **使用这段音频**。
5. 音轨资料里会出现文件名和试听控件。BPM、调性空着时，选好音频后会**自动识别**并填进去（几秒钟，在你的浏览器里完成），觉得不对可以直接改；也可以点 **自动识别 BPM / 调性** 重新识别。调性用 DJ 软件常见的简写：`Am` 是 A 小调，`F#` 是升 F 大调。
6. 右侧的「特色图片 / 特色图像」用于封面；没有封面时，网站使用磁带图形。
7. 点击发布。新曲目会出现在 Beats 页面和播放器的队列与双盘控制台曲库中。

建议网页试听使用 MP3、M4A 或 Ogg。WAV 也可以上传，但文件较大，访客等待和服务器流量都会增加。Docker 示例配置的单文件上传上限为 256 MB；普通 WordPress 安装的上限由你的服务器配置决定。

未选有效音频时，发布操作会提醒补充，记录保留为草稿。草稿不会出现在公开曲库。WordPress 媒体附件使用公开 URL，草稿状态控制的是内容展示。

## 修改和删除

- **改曲名、BPM、调性或介绍**：打开对应 Beat，修改后点击更新。
- **批量补 BPM / 调性**：在「DEVDJAM」控制室首页点 **识别缺失的 N 首**，会逐首分析并保存，只补空着的，不改你填过的。
- **替换音频**：重新选择或上传音频，然后更新。这会更换关联，不自动删除旧文件。
- **移除关联**：解除当前 Beat 与音频的关联。若该 Beat 已发布，将保存为草稿，避免曲库中出现没有音源的曲目。
- **删除文章 / Beat**：先移入回收站，可以在回收站里恢复；彻底删除是单独操作。
- **删除音频文件**：在媒体库中删除。一个音频可能被多个地方引用，删除后相应曲目无法继续播放。

后台修改后，前台刷新或切换栏目会重新读取曲库。正在播放的音频会尽量维持，撤下当前曲目后重新加载曲库会停止它。

## 播放器

- 首次进入网站不会自动出声。点击一首 Beat 或播放器播放按钮后开始播放。
- 支持播放 / 暂停、上一首 / 下一首、拖动进度、音量、展开队列选曲。
- 在站内导航切换首页、音乐、Beats、杂谈、链接和关于时保持播放。
- 刷新整个网页、离开本站或打开管理后台会重新加载页面；重新进入后等待访客手动播放。
- 网络或音源出错时显示提示和重试按钮。
- 音量偏好保存在访客自己的浏览器。「控制面板」的动效开关可以减少装饰动效，也会遵守系统的减少动态效果设置。

## 链接、关于和首页

「链接」和「关于」是 WordPress 页面，在后台「页面」列表中编辑即可。它们初始正文为空，前台显示简短的空状态。

首页自动读取最新已发布内容。欢迎文字、背景和拼贴属于主题设计，不会作为虚构文章或歌曲进入数据库。外观素材路径与来源记录在 `ASSETS.md`。

## 保存自己的内容

服务器备份应同时包含数据库与 `wp-content/uploads`，否则只有文字记录或只有音频文件都不完整。Docker 部署的数据卷和备份方法见 `DEPLOYMENT.md`。


## 留言簿、控制面板、打碟机、进站页

- 「留言簿」页面开放评论，访客填名字和留言即可提交；后台「评论」菜单里审核、回复或删除。其他页面和文章默认关闭评论。
- 「控制面板」：语言下拉（EN / 中文，只切换界面文案，不翻译你写的内容）、三套配色（milk 白底 / ink 黑底 / cherry 红色点缀）、动效开关（星星拖尾、跑马灯、进站页闪烁）。选择保存在访客自己的浏览器里。
- 每个窗口标题栏的 _ 和 □：最小化后再点一次恢复；□ 会把这个窗口弹出到最上层放大显示，其他窗口原地不动（留一个虚线占位），点暗色遮罩、按 Esc 或再点 □ 收回。同一时间只弹出一个。状态只在本次访问内保留。
- 桌面左侧是常驻导航，包含后台入口、播放指示灯和时钟；窄手机屏改为底部任务栏。
- 「dj deck」打碟机（侧栏）：转盘按住拖动可搓碟（第一次按住时后台开始解码，之后搓碟有声音、可倒放）；cue 回到 CUE 点（默认开头）；loop 单曲循环；shuffle 随机下一首；pitch 变速 ±10%（旁边 0 归零，bpm 读数会跟着变）；vol 是总音量；low / mid / hi 三段均衡（左拉到底为完全切除）；「⤢ dj controller」打开双盘控制台。
- 进站页：每次新开浏览器会话第一次访问会显示哥特体大字 "you are now entering devdjam's world"，点击进入；同一会话内不再出现。
- 贴纸散落在各窗口角和栏目空隙里，都能点：有动效并触发对应动作（换配色、下一首、静音、跳转栏目等）。
- 左栏「访客」计数器是真实数据：每个浏览器每天记一次，保存在 WordPress 选项 `devdjam_hits` 里。

## DDJ 双盘控制台

打碟机窗口点 □（或侧栏的「⤢ dj controller」）会弹出一台仿 Pioneer DDJ 的双盘控制器。Deck 1 就是侧栏播放器，Deck 2 只能在这里装载。

- **布局与装载**：顶部从左到右是波形、紧凑曲库、BEAT FX；曲库与 FX 面板大小接近，列表内部滚动。每行的 `1 / 2` 按钮把歌曲装到对应盘，装载后再点该盘播放；也可以拖动中间的 BROWSE 旋钮或用方向键选曲，再按 ◀ LOAD / LOAD ▶。双击整行优先装到未播放的盘；两盘都在放时，会选交叉推子接近切出的那盘，否则不装载。明确点击 LOAD 会替换指定盘的曲目。
- **手机**：打开大控制台后自动横向排布。竖握手机时，整个窗口顺时针旋转 90°；手机本身横过来后恢复正常方向，不要求解除系统旋转锁或进入浏览器全屏。放不下时可在窗口内滚动。打开期间暂时隐藏任务栏，点击标题栏 □ 收回后恢复；小播放器不变。
- **旋钮与推子**：按控件自身的方向拖动，旋钮上下拖；双击恢复默认，键盘 Shift + 拖动可微调。旋转后的触摸坐标已转换，转盘、波形定位与选歌也使用同一方向规则。
- **屏幕**：每台一行信息（曲名、SYNC / MASTER / LOOP 状态、实际 BPM、调性、变速、剩余时间），下面是跟着播放滚动的放大波形（竖线是拍线，粉色中线是播放头，彩色竖线是热点）和整首总览（点哪跳哪）。右侧 `q` 开关量化（循环、热点、CUE 自动吸附到拍），`+ / −` 缩放波形。
- **转盘**：按住黑胶部分拖动 = 搓碟（有声、可倒放，松手按电机速度回到正常）；拖外圈 = 临时加速 / 减速对拍。
- **TEMPO 推子**：方向和 Pioneer 一致，往下是加速。下面的 ±10 切换量程（6 / 10 / 16 / 50）。BEAT SYNC 让这台跟另一台对齐速度和拍位（会自动选倍速 / 半速），手动推 TEMPO 会解除同步。当前变速会同时改变音高，没有保调功能；屏幕的调性仍是曲目保存的值。
- **CUE / PLAY**：停着时按 CUE 在当前位置设点；在 CUE 点上按住 CUE 试听、松手回点；播放中按 CUE 回点并停。SHIFT + CUE 回到开头，SHIFT + PLAY 从 CUE 点重新起播。按住键盘 Shift 等同按住 SHIFT。CUE 试听走正常混音输出，没有独立的耳机预听通道。
- **打击垫**：HOT CUE（空垫设点、有点就跳，SHIFT + 垫删除；停着时按住试听）、BEAT LOOP（1/4 到 32 拍循环，再按一次退出）、BEAT JUMP（前后跳 1 / 2 / 4 / 8 拍，循环中会带着循环一起移动）、SAMPLER（HORN、SIREN、LASER、RISER、BOOM、KICK、CLAP、STAB 八个合成音色，SHIFT + 垫停止）。热点与 CUE 点按曲目保存在访客自己的浏览器里。
- **LOOP 行**：IN 设入点（按住约半秒直接开 4 拍循环）、OUT 设出点开始循环、EXIT 退出 / 重新进入、½X 与 2X 改变长度。
- **混音台**：每路 TRIM、HI / MID / LOW（左拉到底完全切除）、CFX（向左低通、向右高通），电平表，通道推子；中间 MASTER（与侧栏 vol 是同一个）和总电平表；最下面 Crossfader（居中时两路都是满音量）。
- **BEAT FX**：fx▸ 切换 ECHO / REVERB / FLANGER / PHASER / ROLL / TRANS，◀ ▶ 选拍长，CH 1 / 2 / M 选作用在哪一路，LVL 旋钮控制深度，ON 开关（开着时按拍闪烁；回声和混响关掉后会自然拖尾）。
- 关掉控制台时 Deck 2 如果还在放会继续放，侧栏屏幕会显示粉色的 `2▶` 提醒。
- 控制台打开时 Deck 1 播完会停在曲尾（像真唱盘一样）；平时侧栏播放则自动下一首。

**让拍网格更准**：控制台第一次装载一首歌时会下载整首并分析，自动估算 BPM 和拍位。后台保存过 **BPM**（手填或自动识别）的歌，分析会以它为准只做细调，结果最可靠。现场觉得拍线不准时，在歌播放时跟着拍子按那台的 **TAP** 键 4 下以上即可校正（这首歌会记住）；SHIFT + TAP 恢复自动分析。

**加载状态**：`loading` 表示仍在下载或分析，精确循环和有声搓碟要等解码完成。`stream only` 表示分析失败后保留普通播放，重新装载曲目可重试，不能只凭按钮亮灯判断这些功能已经可用。

**访问方式**：优先使用 HTTPS 正式入口，见 [部署说明](DEPLOYMENT.md)。浏览器支持时优先使用音频工作线程；HTTP 备用入口或不支持的浏览器会回退到兼容模式。兼容路径更依赖主线程，页面繁忙时可能出现卡顿。
