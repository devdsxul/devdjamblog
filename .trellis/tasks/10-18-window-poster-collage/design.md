# 设计：窗口海报拼贴

## 渲染分层

每个窗口从下到上四层，只有第二层是新东西：

| 层 | 内容 | 现状 |
| --- | --- | --- |
| 0 | 桌面不规则拼贴墙（`html` 背景） | 已有，改成错落叠贴 |
| 1 | 窗口自己的拼贴版（`.window` 的 `background-image`） | **新增**，每个窗口一张，`cover` |
| 2 | 窗口内各内容面板（列表行、日历格、卡片、输入框） | 由实白改成半透白 |
| 3 | 文字与 1px 描边、硬投影 | 不动，保持零圆角与实色 |

海报在"面板之间的留白"处接近满强度，在列表行里被面板压到约两成——这就是"透出来但字看得清"的落点。

## 变量策略

`--win` / `--win-2` 现在同时被当作**背景色**和**文字色**（`site.css` 8 处 `color: var(--win)`，`deck.css` 3 处）。直接把它们改成半透，会把那 11 处文字一起洗淡，所以拆开：

1. 新增 `--on-solid`：`:root` 为 `#ffffff`，Ink 为 `#111111` —— 与今天 `--win` 在各主题下的取值一一对应，只替换那 11 处 `color: var(--win)`，语义不变。
2. `.window` 作用域内重定义 `--win` / `--win-2` 为半透值，所有继承它的**背景**自动变半透，不必逐条改 30 处声明。
3. `.window` 自身的 `background: var(--win)` 改为 `transparent` + `background-image: var(--win-plate)`，避免"窗口一层 + 面板一层"重复洗，把海报压没。

```css
:root { --on-solid: #ffffff; --win-plate: none; }
.window { --win: rgb(255 255 255 / .82); --win-2: rgb(255 255 255 / .70);
          background: transparent; background-image: var(--win-plate);
          background-size: cover; background-position: center; }
html[data-theme="ink"] .window { --win: rgb(26 26 26 / .86); --win-2: rgb(20 20 20 / .74); }
```

Ink 的 `--on-solid` 取 `#111111`，Cherry 沿用 Milk（它只改强调色）。

## 每窗口一张拼贴版

`--win-plate` 按窗口类挂，避免给每个 `<section>` 写内联样式：

| 窗口 | 类 | 版式 | 目标比例 |
| --- | --- | --- | --- |
| visitors | `.win-visitors` | 2 张竖版叠贴 | 3:4 |
| dj deck | `.win-player` | 2 张，偏下，避开转盘 | 3:5 |
| 文章/首页 | `.win-content` | 3 张，错落 | 3:2 |
| calendar | `.win-calendar` | 2 张横置 | 5:4 |
| study group | `.win-study-group` | 2 张 | 3:4 |

贴法：组内随机 ±6°、互相叠压 8–18%，带 1px 深色边和 2px 硬投影（不用模糊阴影，符合 DESIGN.md）。整版预先烘一层 22–28% 的白纱（Ink 用黑纱），保证"满强度区"也只是隐约可见，不至于像贴错图。

素材体积：5 张窗口版，单张 ≤ 180 KB；桌面墙重压后 ≤ 500 KB；合计 ≤ 1.3 MB。

## 桌面：不规则拼贴

去掉 4×11 网格。重排为散贴：海报尺寸分三档（大 460–620px、中 300–420px、小 220–280px），随机角度 ±4°，互相叠压 10–25%，仍然铺满 2560×1440 并溢出边缘。压暗程度保持上一版（约 40% 亮度）——站主选择保留整面墙，但它是配角，不能再亮。

## 明确排除

- **最大化 DJ 控制器**：`.win-player.is-max` 里是密集 LCD 读数与硬件面板，`.ddj` 内恢复 `--win: #ffffff` 实底，海报只留在控制器外的窗口边角。
- **标题栏**：粉白渐变是 Win98 的识别符号，保持实色，不铺海报。
- **进站门**：继续用桌面墙做淡底，不单独做窗口版。

## 兼容与回退

- `--win-plate: none` 是缺省值：任何没挂到版的窗口（含将来新增的分区）自动退回"半透面板 + 桌面墙"，不会出现空图框。
- 全部是 CSS 变量与背景替换，PHP 结构、`data-window` 拖拽、最小化/最大化、PJAX 均不触碰。
- 移动端窗口高度变化大，靠 `cover` + 居中构图吸收；拼贴版构图做主元素居中，裁到任何比例都至少留一张完整海报。

## 验证

1. 本地 WordPress Playground（8787）+ 无头 Chrome，截 1440×900 / 430×932 / Ink / 最大化控制器五种状态。
2. 取面板内像素算正文对比度（目标 ≥ 7:1）；不足就提高该面板 alpha 或降低海报亮度。
3. `node dev/check.mjs` 语法闸；`git diff` 只应出现 CSS 变量与背景声明。
