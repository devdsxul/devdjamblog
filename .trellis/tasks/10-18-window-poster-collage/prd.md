# 窗口海报拼贴背景

## Goal

海报不再只当桌面壁纸（规则 4×11 网格）：改成**桌面一面不规则拼贴墙 + 每个窗口自己一张拼贴版**，海报从面板后面透出来，字仍然看得清。

## Background

上一轮把桌面换成了 44 张海报的规则网格墙。实际渲染时窗口全是实白底，墙面只在缝隙和页头露出，观感接近纯黑，拼贴设计等于没生效。站主要的是不规则拼贴，并且希望海报直接进窗口内部；透明度可以更高，只要文字可读。

## Confirmed Facts（仓库证据）

- 窗口统一由 `functions.php:119` 的 `dj_window_open($title, $class, $icon)` 输出：`<section class="window {class}" data-window="{id}"><div class="title-bar">…</div><div class="window-body">`。
- 首页 5 个窗口类：`win-visitors`（`index.php:164`）、`win-player`（`:177`）、`win-content`（`:182`）、`win-calendar`（`:195`）、`win-study-group`（`:198`）。
- 窗口底色 `background: var(--win)`（`site.css:554-562`），主体内边距 `margin: 8px`（`:716`）；`--win: #ffffff` / `--win-2: #fafafa`，Ink 改 `#1a1a1a` / `#141414`（`:5-41`）。
- `--win` / `--win-2` 共 42 处引用：33 处作背景，11 处作文字色（`site.css` 8、`deck.css` 3），例如 `site.css:715`、`:1570-1571`、`deck.css:374`。
- 列表行、日历、`.home-entry-list`、输入框等内层元素直接吃 `var(--win)` 实底，所以只给 `.window` 加背景图，图片只会露在 8px 缝隙里。
- 当前桌面：`html` 叠 `var(--desktop-scrim), var(--desktop-image)`，`cover` 不平铺（`site.css:50-60`）；进站门 `.enter` 垫同一张墙（`:1605-1616`）。
- 海报池 73 张、约 250×370，源料与拼版脚本在 `dev/poster-collect/`（`fetch.py` / `compose.py`，池内 `*.jpg` 已 gitignore，成品才进主题）。
- 最大化 DJ 控制器（`.win-player.is-max`）内部是密集 LCD 读数与硬件面板，`deck.css` 另有整套配色。

## Requirements

- **R1 不规则拼贴**：桌面与窗口背景都放弃等尺寸网格；海报错落、分档大小、部分旋转叠压。
- **R2 每窗口一张拼贴版**：5 个窗口类各一张独立拼贴图，同一窗口内 2–4 张倾斜叠贴，不是全局一张图平移。
- **R3 内层半透**：窗口内容面板改成半透白（Ink 下半透明深色），海报从面板后透出；正文可读性不接受倒退。
- **R4 可见度上调**：海报比上一版明显，允许接近满强度出现在面板留白处。
- **R5 三套主题成立**：Milk / Cherry / Ink。
- **R6 不动结构**：不碰 PHP 结构与窗口交互（拖拽、最小化、最大化、PJAX），不影响移动端 ≤600px 任务栏与既有 QA 断言。
- **R7 缺省可退**：没有拼贴版的窗口自动退回"半透面板 + 桌面墙"，不出现空图框。

## Decisions

- **D1 桌面保留整面不规则拼贴墙**（站主拍板）：墙面仍是配角，压暗程度沿用上一版（约 40% 亮度）。
- **D2 半透靠作用域变量**：`.window` 内重定义 `--win` / `--win-2` 为半透，让所有继承背景自动变透，不逐条改 33 处声明；文字色拆出 `--on-solid`（Milk `#fff` / Ink `#111`，与今日 `--win` 各主题取值一一对应）。
- **D3 `.window` 自身不再铺实底**：`background` 改 `transparent` + `background-image: var(--win-plate)`，避免"窗口一层 + 面板一层"重复洗淡海报。
- **D4 最大化 DJ 控制器内部保持实底**：`.ddj` 区域恢复 `--win` 实色，海报只留在控制器外的边角。
- **D5 标题栏不铺海报**：粉白渐变是 Win98 识别符号，保持实色。

## Out of Scope

- 不做海报放大预览、hover 换图，不加新文案。
- 不为每篇文章单独生成海报。
- 改动进站门的星场结构（继续用桌面墙做淡底）。

## Acceptance Criteria

- [ ] 1440×900 截图：桌面是不规则拼贴，5 个窗口各是一张不同拼贴版，桌面不再是 4×11 网格。
- [ ] 面板留白处能认出具体海报，正文区块内海报呈"雾下透出"状态、不抢字。
- [ ] 正文对比度 ≥ 7:1（按面板内最亮海报取样）；标题栏、按钮、LCD 读数保持实色可读。
- [ ] Ink 与 Cherry 两套主题下同样成立；最大化控制器读数区不发灰。
- [ ] 430×932 移动端：拼贴按 `cover` 裁切，无拉伸、无重复接缝。
- [ ] 窗口最小化/恢复、拖拽、加载态下背景不错位、不闪烁。
- [ ] 新增素材单张 ≤ 180 KB、合计 ≤ 1.3 MB（含桌面墙）。
- [ ] `node dev/check.mjs` 通过；`git diff` 只含 CSS 变量与背景声明，无 PHP 变更。
