# 技术设计

## 边界
改动主题的桌面外观层，保留 WordPress 模板结构、Win98 窗口、音频引擎和 SPA 生命周期。单任务交付，背景/贴图/字体共同构成同一视觉验收，不拆独立子任务。

## 视觉方案（按用户最终反馈）
使用参考站原版紫色绸缎桌布与云朵纹理，Ink 使用原版星空。header 透明，与整页共用底纹，不使用独立深色背景、边框或底部锯齿。保留 DEVDJAM 哥特字标及现有贴纸，增加四张原版天体小图；只调整既有文字字体，不新增欢迎语或标语。

## 入口和数据流
- assets/site.css 与 assets/img/：新增局部背景变量/规则和小尺寸平铺图；统一 html 与首页下半区纹理来源，避免两处冲突。不重写整张样式表。
- index.php 页头：仅增改与编排装饰层，不挪动播放器或页面路由容器；必要的首页局部装饰限定在 views/home.php。
- functions.php：复用 GIF 名称→文件/尺寸登记和 dj_sticker()；新增纯装饰与有动作贴纸分开，保持稳定 sticker 身份及现有交互。
- assets/fonts/、docs/ASSETS.md：优先现有明确许可字体/系统字体。新增来源记录只覆盖本次使用与更换项。
- site.js 原则上不改；仅新增动图静态降级无法靠现有机制满足时，沿现有 fx/reduced-motion 通路做小改，不引入第二套状态。

## 素材处理
参考站 URL 是候选，不是已审核资源。下载每批放独立空目录；检查真实格式、尺寸、体积、内容和来源后，才拷入 assets。不得运行下载来的脚本。避免整张大型 sprite、整页截图、品牌图和音乐。SVG 原创或审查无脚本/外链，GIF 配静态替代。用户明确要求非商用直接使用，不替代；记录原始来源和声明，不宣称商业许可。

## 兼容与取舍
不照搬参考站绝对坐标长画布；桌面在可用外围空间拼贴，手机依赖正常文档流和少量定位。装饰 pointer-events:none、aria-hidden；交互贴纸保留键盘操作与 aria-label。图片明确宽高，避免 CLS。尊重现有动效关闭，不能用 CSS animation:none 冒充 GIF 停止。

## 回滚
所有变更限本任务文件和新增素材。回滚时逐项恢复本任务 diff 和取消新增资源引用；不 reset、清理、覆盖用户未提交改动，不执行生产或数据库操作。此设计已获用户确认，不构成提交/推送授权。
