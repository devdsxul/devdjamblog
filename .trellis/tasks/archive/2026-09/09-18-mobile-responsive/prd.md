# 适配移动端响应式布局与触控体验 (Mobile Responsive Adaptation)

## Goal

为 DEVDJAM 音乐博客打造专业、丝滑且极具沉浸感的移动端/手机屏幕（<=600px，重点覆盖 360px~430px 主流手机）浏览与交互体验。在严格延续 Win98 复古白底黑线美学、GifCities 贴纸趣味与打碟机功能的前提下，将左侧导航栏转为经典的 **Win98 底部任务栏（Taskbar）**，彻底释放主体阅读视口至 100% 全宽，并全面优化触控人体工程学。

## Confirmed Facts & Decisions

1. **核心架构与技术栈**：单仓库前端项目，基于原生 CSS 和 `98.css`，无外部重型前端框架依赖。
2. **移动端导航形态（已确认）**：
   - 手机小屏（`<= 600px`）下，左侧固定侧边栏 `.dock` 重塑为屏幕底部常驻的 **Win98 经典任务栏 (Taskbar)**。
   - 带有 Win98 像素 Logo / 开始按钮形态、横向平滑排列核心栏目、右侧常驻时钟与托盘状态。
   - 主体桌面与窗口占据屏幕 100% 宽度，底部保留任务栏安全内边距。
3. **触控人体工程学规范**：
   - 触控目标（Touch Target）不小于 40×40px，窗口最小化/最大化、音频播放/上一首/下一首按钮杜绝误触。
   - 移动端输入框（评论表单、搜索）字体尺寸保持 `>= 16px`，防止 iOS Safari 页面被动放大。
4. **规范与约束**：
   - 严禁出现窗口关闭按钮（×），严格保留最小化（-）与最大化（□）；
   - 严禁外链图床，严格使用本地 `assets/` 资源；
   - 严格维护 Win98 边框、阴影与调色板；
   - 所有变更必须通过 `npm run check`。

## Requirements

### 1. Win98 经典底部任务栏 (`.dock` <= 600px)
- **固定位置**：`position: fixed; bottom: 0; left: 0; right: 0; z-index: 1000; height: 44px;`，采用经典 Win98 浅灰底色与立体凸起上边框。
- **任务栏组件**：
  - 左侧：**开始/DEVDJAM** 徽标按钮（`icon-win.gif` + 粗体文字）。
  - 中部：横向滑动的栏目按钮条（杂谈、音乐、Beats、链接、关于、留言簿），支持 `-webkit-overflow-scrolling: touch`，带有立体边框与选中状态。
  - 右侧：系统托盘区（播放动态 LED 指示灯 + 像素时钟）。
- **视口安全垫**：`.desk-layout` 与 body 底部增加安全内边距（`padding-bottom: 50px`），确保页面滑动到底部时不被任务栏遮挡。

### 2. 移动端主内容与窗口 100% 全宽重构
- **桌面布局**：`.desk` 彻底取消左侧 margin，单列纵向自然流动，主内容窗口（`.win-content`）撑满屏幕可用宽度。
- **首页单列卡片重塑**：
  - `.home-hero` 在手机端以精致比例垂直排列，封面居中或全宽，文字不溢出。
  - `.home-split` 音乐与 Beats 模块单列自适应，列表项 `.home-beat-item` 封面、标题、BPM 与播放按钮在小屏清晰对齐。
- **文章与长文本阅读**：
  - `.prose` 排版针对手机屏调优行高与外边距。
  - 宽表格与代码块支持局部横向滚动（`overflow-x: auto`），禁止撑爆外层视口。

### 3. 触控与交互优化 (Touch Ergonomics)
- **窗口控制按钮**：`.title-bar-controls button` 增加触控热区（pseudo-element 或 padding），手机单手操作顺手精准。
- **音频控制**：
  - 侧边栏打碟机单盘控制器按钮触控区放大。
  - 播放进度条 `.seek-slider` 与推子在触屏上提供更易拖拽的滑块触点。
- **进站开屏页 (`.enter`)**：
  - 3D 哥特文字 `entering` 和副标题自适应屏幕宽度，手机端不换行不错位。

### 4. 双盘工作台最大化 (`.player-pro`) 手机端体验
- 窗口最大化时覆盖全屏视口，支持双盘与混音器的横向平滑滑动，曲库列表支持触摸快速点播。

## Acceptance Criteria

- [ ] **AC1 底部任务栏**：在 `<= 600px` 视口下，`.dock` 固定在屏幕最底部，呈现正统 Win98 任务栏外观，核心导航点击畅顺，内容区完全展开且底部不被遮盖。
- [ ] **AC2 移动端全宽**：在主流手机分辨率（360px, 375px, 390px, 414px, 430px）下，主内容窗口、文章页与归档列表撑满视口，无全局横向晃动或多余空白。
- [ ] **AC3 触控友好**：窗口的最小化/最大化按钮与曲目播放按钮触控精准；输入框获得焦点时 iOS Safari 不发生意外自动放大页面。
- [ ] **AC4 双盘播放器**：全屏最大化播放器在手机端无错位崩溃，横向滚动操作顺畅。
- [ ] **AC5 语法验证**：执行 `npm run check` 校验通过，0 语法错误。

## Out of Scope

- 不破坏桌面端（> 600px）原有的左侧 Dock 与三栏窗口桌面。
- 不引入外部 CSS/JS 依赖库。
- 不更改 WordPress 后端 PHP 路由与数据接口。
