# Pioneer 风格 DJ 控制台 + 全站细节风格统一

## Goal

把放大后的打碟机重做成 Pioneer DDJ（DDJ-400 / FLX4）风格的双盘控制器，做到"真能打"：
真实搓碟（有声音、可正反向）、热点 / 循环 / 跳拍 / 采样四种打击垫、混音台与 BEAT FX；
同时统一全站细节风格：纯黑标题栏换成更协调的浅色标题栏、页面底部加框收口、修复登录后底部被截断。

## 来源（用户原话）

1. 完善 dj deck 的功能、操作、布局，like a real pioneer dj controller，支持搓碟，风格统一，遵循 neocities 设计。
2. 统一、优化整体风格，主要是小细节上的风格统一；页面最下方有被截断的感觉，加个框把底部收一下；纯黑的顶栏不太搭，尝试改一下。

## Requirements

### R1 双盘控制器布局（放大后的 DJ DECK 窗口）
- 仿 DDJ-400/FLX4：左右两个同构 Deck + 中置 Mixer + 下方曲库浏览器。
- 每个 Deck：顶部信息屏（曲名、BPM、调性、变速 %、剩余/已播时间切换、总览波形可点击跳转）；
  LOOP 区（IN / OUT / 4 BEAT·EXIT / ½X / 2X）；大号 Jog 转盘；外侧 BEAT SYNC + TEMPO 推子 + 变速范围切换；
  打击垫模式键（HOT CUE / BEAT LOOP / BEAT JUMP / SAMPLER）+ 8 个打击垫；左下 SHIFT / CUE / PLAY·PAUSE。
- Mixer：LOAD 1 / BROWSE 旋钮 / LOAD 2；每通道 TRIM / HI / MID / LOW / CFX 旋钮、通道电平表、通道推子；
  MASTER 旋钮 + 主输出电平表；Crossfader；BEAT FX 单元（效果选择、BEAT ◀▶、CH 1/2/M、LEVEL/DEPTH、ON/OFF）。
- 顶部"屏幕"：两轨滚动放大波形（rekordbox 式），带拍线、播放头。
- 所有控件必须真实可用，不留摆设按钮（现有 pro/XY PAD/FX 下拉/错位 EQ 等空壳全部移除）。

### R2 真实搓碟与演奏功能
- Jog 顶面按住拖动 = 搓碟：音频跟随手势正反向播放（有声音），松手后按电机惯性回到正常速度。
- Jog 外圈拖动 = 变速微调（pitch bend），松手恢复。
- CUE 按 CDJ 规则：停止时按下设 Cue 点；在 Cue 点按住试听、松开回 Cue；播放中按下回 Cue 并暂停。
- HOT CUE：空垫设点、已设垫跳转；暂停时按住试听；SHIFT+垫删除；按曲目持久化。
- BEAT LOOP：1/4…32 拍循环；BEAT JUMP：±1/2/4/8 拍（循环中则移动循环）；SAMPLER：8 个合成音效（气笛等）。
- BEAT SYNC：按拍速对齐另一盘并锁定；有拍网格时对齐相位。
- 无 BPM 元数据的曲目自动估算 BPM 与拍网格。

### R3 紧凑模式（侧边栏）保持站点播放器职责
- 继续作为全站常驻播放器（Deck 1），跨页面不断播；播放、上下曲、进度、音量、变速、EQ、队列、重试照常。
- 紧凑转盘同样支持搓碟；未解码前退化为静音拖动定位。
- 普通访客只点"播放"时不额外下载/解码整首音频（按需解码）。

### R4 全站细节风格统一
- 窗口标题栏：去掉纯黑填充，改为与白底黑线 + neocities 风格协调的浅色标题栏（三套配色均正常）。
- 页面底部：新增底部状态栏把整页收口；登录状态下 admin bar 不再把底部顶出视口。
- 统一细节：滚动条、悬停/选中态颜色、移动端任务栏、残留的硬编码颜色与 emoji 等不一致处。

### R5 交付（用户追加指示："做完直接提交推送并部署生产"）
- 完成并验证后提交代码、推送分支到 origin，并按本地运维手册同步主题文件到生产服务器（部署前先在服务器做备份）。
- 生产站为纯 HTTP（非安全上下文，AudioWorklet 不可用）：有声搓碟等 buffer 功能必须在生产环境也能工作。
- 部署后验证生产站：页面 200、新资源可访问、PHP 无报错、浏览器无控制台错误。
