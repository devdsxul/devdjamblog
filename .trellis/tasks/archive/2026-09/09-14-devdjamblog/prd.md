# DEVDJAM 迷幻地下音乐博客

## Goal

为 DEVDJAM 建立可部署到用户自有服务器的个人音乐博客：访客能阅读地下音乐分享和杂谈、收听用户发布的 beat；站主能在成熟的管理后台自行上传、修改、发布和删除内容。

## Requirements

- R1：制作首页、音乐、beats、杂谈、链接与关于等完整导航和响应式界面；在桌面保留老网页的密集布局与装饰，在手机上正常阅读。
- R2：采用 WordPress 原生管理后台和专属主题，提供登录、文章编辑、草稿/发布、分类、媒体管理和内容删除。
- R3：beat 可配置标题、音频文件、封面及可选 BPM/调性/介绍。后台保存后，已发布内容出现在前台。
- R4：站内播放器支持播放/暂停、切歌、进度拖动、音量和播放队列；访问站内栏目时尽量保持音频连续播放。首次访问不自动出声。
- R5：首次启动没有演示文章、演示歌曲、虚构发布日期或假访问计数；空列表和播放器的空状态须与视觉融合且容易理解。
- R6：管理区写入受认证和授权保护；公开页面只展示已发布内容；音频、图片和数据库必须可持久化与备份。
- R7：交付本地项目、环境示例和适合服务器部署的说明；不连接或修改现有生产服务器，不提交 Git。

- R8：桌面端布局占满视口宽度，左右两侧无空白留边；前台不出现说明性文案、口号、功能介绍和中文解释行，只保留导航、标题、内容与最简状态提示。
- R9：装饰素材直接使用 GifCities 的 GIF 与 sadgrl.online 提供的平铺背景等资源，随主题本地打包；不在页面放置指向这些站点的链接徽章；素材来源记录在 docs/ASSETS.md。
- R10：站内导航切换应即时：悬停/按下预取、内存缓存已访问页面、缓存命中时立即替换正文并后台刷新。
- R11：视觉升级为 Windows 98 式复古界面（窗口标题栏、斜面按钮、像素字体、平铺背景、动图贴纸），在紫色主色之外加入青色、粉色、黄色、绿色等点缀色；不保留参考图裁片。
- R12：右上角控制面板提供界面语言 EN/中文切换与动效开关（2026-09-16 按用户要求移除控制面板主题切换与前台 RSS 按钮，固定 Milk 白底黑线粉色点缀风格）；界面文案由 JS 字典切换，用户内容不翻译。
- R13：Neocities 式组件：站内搜索、日历、留言簿（WordPress 评论）、真实访客计数、最近更新、开始菜单、鼠标星星拖尾、跑马灯状态栏。
- R14：每个窗口的最小化/最大化按钮可用（再点恢复），无关闭按钮；状态保存在会话内。主导航为左侧常驻侧边栏。
- R15：配色为白底黑线 + 粉色点缀（milk），另有 ink（黑底）与 cherry（红点缀）；不使用蓝紫渐变。
- R16：打碟机：转盘搓碟、cue、loop、shuffle、pitch ±8% 与 bpm 联动、三段 EQ（Web Audio，失败静默降级）、音量、队列。
- R17：进站页：会话内首次访问显示 "you are now entering devdjam's world"（哥特体、居中），entering 强调，hover 放大，点击进入后正文正常显示；关闭动效时不闪烁。
- R18：桌面背景纯色（milk 白 / ink 黑），无粉色底纹；贴纸不集中在单独窗口，而是贴在各窗口角与栏目空隙。
- R19（2026-09-16）：每张 GIF 在站内只出现在一个位置（导航图标、窗口标题、贴纸、占位互不重复）。
- R20（2026-09-16）：窗口"最大化"改为独立弹出：放大的窗口居中浮在最上层并有遮罩，其他窗口保持显示并用占位虚框保留原位；同一时间只弹出一个，遮罩/Esc/再点 □ 收回。
- R21（2026-09-16）：全站贴纸支持拖拽至任意位置：指针拖动（移动距离 ≥ 5px）触发自由拖拽并提升层级，释放后停留在目标位置且不误触点击动作；单击（移动距离 < 5px）保持原有的火花特效与交互动作；拖拽位置在会话内（sessionStorage）持久化，双击贴纸可重置回原始布局位置。
