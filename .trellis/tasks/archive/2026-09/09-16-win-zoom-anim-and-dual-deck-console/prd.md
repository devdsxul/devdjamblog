# 窗口放大动画过渡与DJ Deck双盘卡片化控制台

## Goal

1. 为全站所有窗口（`.window`）的放大（Maximize）与恢复（Restore）操作增加丝滑的缩放渐变动画过渡。
2. 将 DJ Deck 播放器窗口放大后的展示形态彻底重构：由原先扁平拉伸的横条改为居中独立长方形立体卡片面板，并升级为功能完整可用的双黑胶转盘（Deck A 与 Deck B）及中置混音台（Mixer + 交叉推子 Crossfader + 曲库直选装载）专业 DJ 系统，视觉严格契合本站 Win98 复古赛博哥特风格。

## Requirements

1. **窗口放大/恢复平滑过渡动画**：
   - 当点击任一窗口的放大按钮或遮罩恢复时，窗口需具备平滑细腻的弹性缩放（Zoom / Scale）与透明度渐变动效；
   - 背景遮罩层（`.desk-dim`）具有淡入淡出过渡。

2. **DJ Deck 放大形态卡片化重构**：
   - 改变先前放大后左右通栏撑满整个视口的扁平单栏样式；
   - 限制放大后的宽高比例为居中竖立/适度黄金比例长方形卡片（`width: min(940px, 94vw); max-height: min(880px, 92vh)`），居中悬浮并带有深色像素硬阴影。

3. **双黑胶转盘（Deck A & Deck B）与混音台系统**：
   - **Deck A（左盘）**：
     - 独立曲目标题、封面贴纸、BPM、当前播放时长/总时长；
     - 拟物黑胶大转盘与唱臂，支持随播放实时旋转并支持鼠标指针按压拖动搓碟（Scratch）；
     - 专属控制组：播放/暂停、Cue（归零起点）、Loop（循环）、Pitch（变速推子）；
     - 专属音频通道（Audio A）。
   - **Deck B（右盘）**：
     - 独立曲目标题、封面贴纸、BPM、当前播放时长/总时长；
     - 拟物黑胶大转盘与唱臂，支持随播放实时旋转并支持鼠标指针按压拖动搓碟；
     - 专属控制组：播放/暂停、Cue、Loop、Pitch；
     - 专属音频通道（Audio B）。
   - **中置混音台（Central Mixer）**：
     - 主 BPM 与动态节拍指示灯；
     - 三段均衡（高频 Hi、中频 Mid、低频 Low）；
     - Deck A 与 Deck B 各自的垂直音量推子；
     - 底部经典水平交叉推子（Crossfader）：滑动可平滑切换 Deck A 与 Deck B 音量或双轨合混；
   - **曲库加载面板（Track Library & Queue）**：
     - 双盘下方提供紧凑的曲目列表，每首曲目均配备 `[Load A]` 与 `[Load B]` 操作按钮，可随时将任意曲目分别载入 Deck A 或 Deck B 进行点播与混音。

4. **侧边栏紧凑模式无缝衔接**：
   - 侧边栏常态下仍展示紧凑单栏播放器（与 Deck A 绑定）；
   - 在侧边栏播放的音频，点击放大后在 Deck A 中无缝继续播放，不会中断。

## Acceptance Criteria

- [ ] 点击所有窗口的放大按钮均有平滑缩放过渡动画；
- [ ] DJ Deck 放大后呈居中卡片状，不再扁平拉伸；
- [ ] Deck A 与 Deck B 双盘均具备独立唱片、唱臂、时间进度与控制，支持独立播放音频；
- [ ] 交叉推子（Crossfader）滑动能精准控制两盘声音混音过渡；
- [ ] 曲库列表中点击 `[Load A]` 与 `[Load B]` 可分别装载曲目并能即时试听；
- [ ] 双盘均支持鼠标按住黑胶搓碟；
- [ ] 运行 `npm run check` 校验通过。
